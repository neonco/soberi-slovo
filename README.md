# 🎯 Логопед — Собери слово

**Последнее обновление:** 18.07.2026
**Цель:** Приложение для логопедических занятий с ребёнком 5 лет (ОНР 2, стереотипная речь)

> Работаешь кодовым агентом? Сначала прочти **[AGENTS.md](AGENTS.md)** (режим общения). Сборка: раздел «Изменение приложения» ниже.

---

## 🚀 Запуск

```bash
cd prototype
npm run dev        # → http://localhost:7100
```
Или просто открыть `prototype/index.html` двойным кликом.

## 📁 Структура

```
prototype/   ← приложение (шаблон + собранный index.html + сервер)
content/     ← базы слов: 143 слова по 7 уровням Марковой + цифры/растения/профессии/глаголы
tools/       ← build.py (сборка), make_icons.py, make_store_assets.py
docs/        ← research.md (методика), docs/images/ (новые паки картинок)
             ARCHITECTURE.md устарел: описывает Flutter, которого в проекте нет
(samples/ с записями голоса ребёнка лежит только локально и в git не попадает)
```

## 🎮 Режимы

| Режим | Что делает |
|---|---|
| 🧩 **Собери слово** | 7 уровней слоговой структуры по Марковой. Тап по слогу → в слот; тап по слоту — возврат; автопроверка после последнего слога; цвета слогов как на бумажных карточках |
| 👂 **Покажи!** | Звучит «покажи …», 4 карточки — выбрать правильную. 14 категорий |
| 🏃 **Что делает?** | Тренажёр 12 базовых глаголов |
| 💬 **Да или нет?** | «Это киса?» — 👍/👎 |

Настройки для взрослых: диктор (7 голосов Яндекс SpeechKit, mp3-файлы), темп ползунком, эмодзи/карточки (185 настоящих карточек), перемешивание слогов и карточек, подсветка ударения, переход к любой карточке уровня (кнопка «2/23 ▾»), запись образцов речи для STT-теста.

Прогресс (освоенные слова) хранится локально в браузере.

## 🔧 Изменение приложения

```bash
# 1. Править prototype/index.template.html и/или content/*.json
# 2. Собрать:
python tools/build.py
```

Новые слова → догенерировать озвучку (Яндекс SpeechKit, 7 дикторов; скрипта генерации в репозитории нет) и картинки (см. ниже).

## 🖼 Картинки

- **Пак 1** — `prototype/images/`, 185 карточек 512×512, плоская пастель на белом фоне. Используется в приложении.
- **Новые паки** (flat с толстым контуром, реалистичные фото на естественном фоне, акварель, аппликация из бумаги) генерируются локально моделью Z-Image Turbo, по 2 варианта на слово. Порядок работы, шаблоны промптов, структура папок и критерии готовности: [docs/images/image-generation-handoff.md](docs/images/image-generation-handoff.md). Промпты по всем 185 словам: [docs/images/image-prompts-v3.csv](docs/images/image-prompts-v3.csv).
- Результат генерации лежит в `prototype/images-v2/` (в git не добавляется, тяжёлый). В приложение подменяются только выбранные картинки из `prototype/images-v2/picked/`.

## 🧠 Контекст ребёнка

- Возраст 5 лет, ОНР 2 (стереотипная речь), активный словарь ~6 слов, нормальный слух
- Подход: расширение слоговой структуры (Маркова), переход от эхолалии к спонтанной речи, без давления на «правильность» — ошибка это мягкая тряска и «попробуй ещё»
